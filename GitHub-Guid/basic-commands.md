

Git یک سیستم کنترل نسخه است که برای مدیریت و ثبت تغییرات پروژه‌ها استفاده می‌شود. با استفاده از Git می‌توان نسخه‌های مختلف یک پروژه را ذخیره و تغییرات ایجادشده را پیگیری کرد. پنج دستور پایه Git عبارت‌اند از:

1. "git init"
   برای ایجاد یک مخزن (Repository) جدید Git در پوشه فعلی استفاده می‌شود.

2. "git status"
   وضعیت فعلی پروژه را نشان می‌دهد؛ مانند فایل‌های تغییرکرده، جدید یا حذف‌شده.

3. "git add ."
   تمام فایل‌های تغییرکرده را برای ثبت در Commit به قسمت Staging اضافه می‌کند.

4. "git commit -m "message""
   تغییرات اضافه‌شده را به عنوان یک نسخه جدید در مخزن Git ثبت می‌کند. عبارت داخل ""message"" توضیحی درباره تغییرات است.

5. "git push"
   تغییرات ثبت‌شده را از مخزن محلی به مخزن آنلاین مانند GitHub ارسال می‌کند.
