# Mergeing
مرج کردن در لغت به معنی ادغام کردن است. یعنی میتوان برنچ های مختلف را ادغام کرد و وارد پروژه اصلی کرد. با دستورات زیر میتوان از مرج استفاده کرد:
# Commands and Description:
## 1```git checkout main``` | Switch to main 
رفتن به صفحه main
## 2git pull origin main| Update main 
برای آپدیت کردن main
## 3git merge BRANCH | Merge another branch 
مرج کردن به بک برنچ دیگر
## 4git status Check | merge status 
چک کردن وضعیت مرج
## 5git add  Stage | resolved files 

## 6git commit -m "MESSAGE"| Commit the merge resolution 
نوشتن یک کامنت برای مرج 
## 7git push origin main | Push merged changes 
اعمال کردن تغییرات مرج
## 8git branch -d BRANCH | Delete local branch 
پاک کردن یک برنچ فعلی
## 9git push origin --delete BRANCH | Delete remote branch 
پاک کردن برنچ اصلی
