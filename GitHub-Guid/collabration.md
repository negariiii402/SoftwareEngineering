# Collaboration
یکی از مزیت های استفاده از GitHub، برای پروژه های گروهی میباشد. در گیت هاب میتوان به صورت گروهی و چندنفره روی یک پروژه کار کرد. در ابتدا برای دعوت افراد به پروژه با فرستادن لینک دعوت ( invite ) یا ارسال ایمیل میتوان افراد را به پروژه اد کرد.
راه های ارتباطی بین افراد شرکت کننده با هم توسط basic-commands ارتباط برقرار میکنند.
